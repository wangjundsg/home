# 双人默契闯关素材外援交底表

## 使用目的

这份文档用于交给外援填写“双人默契闯关”的成人情侣互动素材。外援负责填写具体、直白、可执行的正文；项目内后续只做结构审查、阶段分级、对象关系、游戏机制匹配和安全边界审查。

身份统一：

- 大大怪：男性
- 小怪兽：女性

文案要求：

- 直白、短句、能照着做。
- 不写成长段小说。
- 每条只写一个动作目标。
- 每条都要看得出“谁做、对谁做、做什么、多久或做到什么反馈”。

## 字段说明

| 字段 | 填写要求 |
|---|---|
| 阶段 | 调情 / 前戏 / 深入 / 最终 |
| 分类 | 主动卡 / 回应卡 / 双人卡 / 场景卡 |
| 标题 | 4-10 个字，直接概括任务 |
| 执行主体 | 大大怪 / 小怪兽 / 游戏结果决定 / 双方 |
| 执行对象 | 大大怪 / 小怪兽 / 双方 |
| 动作类型 | 亲吻 / 触碰 / 姿势 / 节奏 / 口令 / 配合 / 收尾 等 |
| 正文 | 一句话，直接说明任务内容 |
| 时长 | 15s / 30s / 60s / 自然完成 |
| 强度 | 1-5 |
| 是否可跳过 | 默认是 |
| 备注 | 适合女方主动 / 适合 Boss / 适合收尾 等 |

## 四类素材写法

### 主动卡

必须明确主动方和对象。主体可以由游戏结果决定，也可以指定大大怪或小怪兽。

推荐句式：

`执行主体` 对 `执行对象` 做一个明确动作，持续 `时长`。

### 回应卡

必须包含“发起动作 + 对方回应方式”。重点是让被动方也有清楚的参与动作。

推荐句式：

`一方` 先发起动作，`另一方` 用动作、语言或节奏反馈来回应。

### 双人卡

必须是双方共同完成，不要长期偏向一方服务另一方。

推荐句式：

`双方` 一起完成一个互动目标，持续 `时长` 或直到双方确认完成。

### 场景卡

可以写得像角色任务、小剧情或 Boss 回合。适合承载女方主动、双方配合、阶段推进类内容。

推荐句式：

进入一个具体场景，规定本回合的主动权、配合方式和完成目标。

## 阶段强度说明

| 阶段 | 强度范围 | 写作重点 |
|---|---:|---|
| 调情 | 1-2 | 建立状态、靠近、眼神、语言、轻度身体接触 |
| 前戏 | 2-3 | 明确升温、主动回应、亲密触碰、节奏试探 |
| 深入 | 3-4 | 姿势、配合、主动权切换、阶段 Boss 感 |
| 最终 | 4-5 | 最终亲密、节奏调整、姿势切换、完成与收尾 |

## 数量目标

第一版填写 64 条：

- 4 个阶段
- 4 个分类
- 每类 4 条

女方主动素材建议优先放在：

- 回应卡
- 场景卡
- 深入阶段
- 最终阶段

这样更像游戏给出的台阶，而不是单方面命令。

## 审查标准

素材回收后按下面标准审查：

- 是否一眼看懂“谁做、对谁做、做什么、多久”。
- 阶段强度是否递进，早期不能突然跳到最终强度。
- 大大怪和小怪兽是否都有参与感，不能长期一方只服务另一方。
- 女方主动是否通过游戏结果、场景或配合任务触发。
- 是否保留跳过、停止、降级空间。
- 文案是否短、直白、可执行。
- 是否能映射进现有字段：`stageKey / taskMode / title / template / intensity / tags`。

## 回收后的入库整理规则

外援填完后，入库前按下面方式整理：

- `标题` 转为 `title`。
- `正文` 转为 `template`。
- `强度` 转为 `intensity`。
- `阶段` 按映射转为 `stageKey`。
- `分类` 按映射转为 `taskMode`。
- `动作类型`、`执行主体`、`备注` 转为 `tags`。
- `是否可跳过` 不直接入素材字段，交给游戏流程控制。

入库模板里需要使用占位符时：

- 游戏结果决定的主动方：用 `{actor}`。
- 被执行对象：用 `{target}`。
- 双方共同完成：用 `{both}`。

示例结构，不代表正文尺度：

```ts
{
  id: 'tpc-custom-001',
  stageKey: 'advanced',
  taskMode: 'scene',
  title: '外援填写标题',
  template: '{actor} 和 {target} 按外援正文完成任务。',
  intensity: 4,
  tags: ['姿势', '女方主动', 'Boss'],
  curated: true,
  source: 'external',
}
```
