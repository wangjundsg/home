# 双人默契闯关素材外援执行规范

## 核心要求

这次不要再按“含蓄氛围卡”写，也不要按“说明书长句”写。

目标是：**短、直白、具体、能照做**。

外援只需要被限制三件事：

- 格式要短。
- 场景要能在家里完成。
- 动作、姿势、对象、时长要具体。

不要再额外降低露骨程度，也不要把最终阶段写成含蓄暗示。

## 统一身份

- 大大怪：男性
- 小怪兽：女性
- 玩家：当前被游戏指定执行任务的一方
- 伴侣：另一方

如需指定性别主动：

- 男方主动：写“大大怪”
- 女方主动：写“小怪兽”
- 公平随机：写“玩家”
- 双方一起：写“两人”

## 格式要求

每条格式：

`标题：主体 + 姿势/动作 + 对象 + 时长或次数。`

正文要求：

- 18-36 字优先。
- 最多 45 字。
- 不写长段解释。
- 不写“发起方、接受方、作为反馈”。
- 不用文学词包装。
- 不用“感觉、氛围、暧昧、掌控全局”代替动作。

好的方向：

- `小怪兽跨坐在大大怪身上，扶肩上下起伏30秒。`
- `大大怪让小怪兽扶住桌沿，从背后进入30秒。`
- `两人在镜前站立结合，看着镜中动作完成60秒。`

不合格方向：

- `玩家调整姿势，体会更深层次的亲密。`
- `伴侣掌握主导权，玩家配合享受这段过程。`
- `两人用最温柔缓慢的节奏唤醒彼此。`

## 场景卡硬规则

场景卡不是“剧情设定”，必须是 **家里具体位置或具体家具/道具 + 姿势动作**。

可用场景：

- 床
- 沙发
- 椅子
- 桌边
- 镜子前
- 墙边
- 浴室
- 地毯
- 门后
- 被子里
- 枕头
- 领带/丝带/眼罩
- 润滑剂/乳液/小玩具

场景卡必须写成：

`在某个家具/位置上，用某个姿势，完成某个动作。`

场景卡不要写成：

- 清晨设定
- 停电设定
- 医生设定
- 女王设定
- 教学模式
- 视觉展览
- 晚归设定
- 主导反转

这些都太空，不够执行。

## 四阶段写法差异

### 调情

可以轻，但也要具体。

写：

- 手腕、脸、耳朵、脖子、锁骨、肩膀。
- 床边坐下、沙发拥抱、镜前整理衣服。
- 脱外套、脱袜子、亲手背、亲锁骨。

不要只写：

- 对视
- 夸奖
- 氛围
- 昵称

### 前戏

要开始明确触碰和衣物变化。

写：

- 沙发半躺亲吻。
- 床边脱上衣。
- 椅子跨坐摩擦。
- 桌边扶腰亲吻。
- 眼罩、丝带、乳液、冰块。

不要只写：

- 感受气息
- 轻柔靠近
- 温柔唤醒

### 深入

要写强前戏、服务、明确姿势准备。

写：

- 手部服务。
- 口部服务。
- 私密处边缘刺激。
- 跨坐、跪姿、腿夹、脸坐、上位准备。
- 谁用手/嘴/玩具对谁做什么。

不要只写：

- 挑逗
- 享受
- 引导
- 主导权

### 最终

要直接写正式阶段的姿势、节奏、切换和收尾。

写：

- 传教士。
- 女上位。
- 后入。
- 侧入。
- 站立镜前。
- 桌边。
- 椅子上。
- 沙发边。
- 九浅一深。
- 快慢切换。
- 释放后清理和拥抱。

不要只写：

- 结合
- 更深入
- 调整角度
- 配合节奏
- 温柔唤醒

这些词太空，要换成具体姿势和动作。

## 四分类写法

### 主动卡

谁主动做动作。

例：

- `大大怪让小怪兽仰躺，抬起她双腿进入30秒。`
- `小怪兽跨坐在大大怪身上，扶肩上下起伏30秒。`

### 回应卡

一方动作，另一方用具体动作回应。

例：

- `大大怪后入30秒，小怪兽主动后顶配合。`
- `小怪兽上位起伏30秒，大大怪扶腰上顶配合。`

### 双人卡

两人共同完成，不偏向单方。

例：

- `两人侧卧结合60秒，一人动腰一人收紧拥抱。`
- `两人在镜前站立结合60秒，同时看镜中动作。`

### 场景卡

必须包含家具/位置/道具。

例：

- `床边：小怪兽扶床沿跪趴，大大怪从背后进入30秒。`
- `椅子：大大怪坐稳，小怪兽跨坐上位起伏30秒。`
- `桌边：小怪兽扶桌沿站立，大大怪从后方进入30秒。`
- `镜前：两人站立后入60秒，全程看镜中动作。`

## 退回标准

出现下面情况，直接退回重写：

- 场景卡没有床、桌、椅、沙发、镜子、墙、浴室等具体场所。
- 最终阶段没有具体姿势。
- 用“主导、配合、亲密、感觉、氛围”代替动作。
- 正文超过 45 字。
- 每条都写成解释句。
- 没有写清谁对谁做什么。
- 没有写清姿势。
- 没有写清时长或次数。
