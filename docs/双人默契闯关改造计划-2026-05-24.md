# 双人默契闯关改造计划

## 目标

直接替换现有“双人默契闯关”，不新增入口，不保留旧交手机玩法。

新玩法改为“同屏可看、轮流推进、轻悬念触发素材”的四阶段路线。游戏本身不是复杂操作挑战，而是一个让两个人自然进入任务素材的体验壳。

## 核心改动

- 保留原入口 `/interact/private/two-player-challenge` 和“双人默契闯关”名称。
- 移除旧机制里的交手机、隐藏选择、遮罩提示、隐藏结果。
- 改为 A/B 轮流参与的路线式流程。
- 每个阶段通过若干“小门”推进，阶段末尾有 Boss 式收束。
- 小门以轻悬念和合作触发为主，例如猜心、委托、主导权、阶段收束。
- 每个门最终触发当前阶段素材卡，完成素材后继续推进。

## 素材规则

- 调情、前戏、深入、最终阶段分别对应现有素材等级。
- `directed`：定向任务，有明确发起者和接受者。
- `response`：回应任务，一方给引子，另一方需要明确反馈、配合或推进。
- `duo`：共同任务，两人一起完成。
- `scene`：场景任务，两人进入一个情境，可更多承载“女方主动一点”的氛围引导。
- 主动权由游戏结果决定，保持公平。
- 场景任务可以更偏向共同配合和引导女方主动，但不能变成强迫。

## 实现方向

- 重做 `TwoPlayerChallengePage` 的状态流：路线推进、当前门状态、素材卡状态。
- 替换 `ChallengeMechanicPanel` 的旧机关 UI。
- 复用现有 `ChallengeTaskCard`、素材模板渲染、阶段素材映射。
- 增强素材选择逻辑，使它能按阶段、任务类型、门结果、主体关系稳定抽取。
- 不影响心跳棋、线下游戏、首页和互动页其它入口。

## 验证

- `npm run build`
- `npm run lint`
- 手动确认：
  - 不再出现交手机、隐藏结果、遮挡提示。
  - A/B 能轮流参与，屏幕始终共同可看。
  - 每个阶段能推进、收束、进入下一阶段。
  - 小门和 Boss 都能触发素材卡。
  - 素材主体合理，actor/target/both 不错乱。
  - 未达成不会卡死，不强惩罚，不破坏氛围。
