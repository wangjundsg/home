# 我们的花园

“我们的花园”是一款给两个人使用的情感维护和互动 PWA。它把日常记录、情侣空间、互动素材、线上双人游戏和后续线下游戏入口放在一个移动端优先的小工具里。

## 开发命令

```bash
npm install
npm run dev
npm run build
npm run lint
```

## 当前重点

- 互动中心直接提供“线上游戏”和“线下游戏”两个入口。
- 线上游戏包含“双人默契闯关”和“双人心跳棋”。
- 线下游戏本轮仅保留入口，后续重新规划。
- PWA 安装名为“我们的花园”，短名为“小花园”。

## 技术栈

React、TypeScript、Vite、Tailwind CSS、Supabase、vite-plugin-pwa。
