# 我们的花园 —— 情感维护工具使用说明书

## 这是什么

一个只属于你们两个人的情感小窝。它不是冷冰冰的条款，而是一座桥——帮你们在吵架时找到台阶，在甜蜜时存下回忆，在无聊时一起玩耍。

> 核心原则：**不是法律条款，而是让两人成为彼此的避难所。**

---

## 如何部署（只需一人操作，5分钟搞定）

### 方法：部署到 GitHub Pages（免费，推荐）

1. 注册/登录 [GitHub](https://github.com)
2. 点击右上角 "+" → "New repository"
3. 仓库名填 `qinggan-weihu`（或任意你喜欢的名字），选择 "Public"，点击 "Create repository"
4. 把整个 `qinggan-weihu` 文件夹里的内容上传到仓库（可以直接拖拽上传）
5. 进入仓库 → Settings → Pages
6. "Source" 选择 "main" 分支，文件夹选 "/ (root)"，点击 "Save"
7. 等待1-2分钟，页面会显示 "Your site is live at https://你的用户名.github.io/qinggan-weihu/"
8. 把链接发给TA

### 方法二：用 Netlify Drop（更简单）

1. 打开 [netlify.com/drop](https://app.netlify.com/drop)
2. 把整个 `qinggan-weihu` 文件夹拖进去
3. 等几秒，获得一个网址
4. 把链接发给TA

## 如何添加到手机主屏幕

这一步很重要！添加到主屏幕后，打开就像原生 App。

### iPhone / iPad
1. 在 Safari 中打开网址
2. 点击底部中间的"分享"按钮（方框+箭头）
3. 往下滑，找到"添加到主屏幕"
4. 名称填"小花园"，点"添加"
5. 桌面会出现一个 🏡 图标，点击打开就是全屏 App

### Android
1. 在 Chrome 中打开网址
2. 点击右上角"⋮"菜单
3. 选择"添加到主屏幕"
4. 确认"安装"
5. 桌面会出现图标

## 各功能怎么用

打开小花园后，底部有 5 个 Tab：

### 🩺 急救（最重要！吵架时第一时间用）

吵架时情绪上头了，打开就能看到三个大卡片：

- **🔴 我生气了/我需要被哄** —— 点开会告诉你"现在可以说什么""千万别做什么"
- **🔴 TA生气了/我需要哄人** —— 教你怎么接住TA的情绪
- **🟢 我们很好，记录一下** —— 甜蜜时也可以来记录

点击建议句子旁边的 📋 按钮，可以一键复制，直接粘贴到微信发给TA。

### 📋 日常（打卡攒积分、换奖励）

这里不是强制打卡，而是**自愿积累**：

| 打卡项目 | 积分 |
|----------|------|
| 每日"我在"信号（发一条自拍/云/"想你"） | +5 |
| 每周深度视频（不玩手机，30分钟以上） | +20 |
| 主动使用启动句 | +10 |
| 记录被爱到的瞬间 | +5 |
| 一周无违规 | +30 |
| 见面完成 | +50 |

积分攒够了，可以去**奖励商店**兑换：

| 等级 | 积分 | 奖励示例 |
|------|------|----------|
| 🥉 小确幸 | 30 | 定制情话、专属表情包、指定一首歌 |
| 🥈 暖心奖 | 60 | 15分钟专属按摩、一次不打断的倾听 |
| 🥇 特别奖 | 100 | 约会全包（≤100元）、手工礼物 |
| 🏆 终极大奖 | 200 | 一日服从对方安排、手写长信+视频念出来 |

兑换后记得去兑现哦～

### 🤝 承诺（双方的约定）

展示你写下的承诺。红线承诺（提分手、人身攻击等）会有红色标记，黄线承诺（翻旧账、敷衍等）有黄色标记。

点击右上角"✏️ 编辑"可以修改你的承诺。TA的承诺需要TA写好后通过导入功能同步过来。

### 🏪 补偿（犯了错怎么弥补）

当有人触犯了规则：
1. 点击"+ 记录"，填写谁、违规内容、级别、补偿方式
2. 触发方完成补偿后，勾选"补偿完成 ✓"
3. 另一方确认原谅，勾选"已收到原谅 ✓"
4. 两个勾都打上后，记录自动归入"已翻篇"，这件事就算过去了

### 🎮 互动（一起玩！）

7 种互动模式：

- **💬 真心话盲盒** —— 抽一张真心话卡片，诚实回答
- **🎯 默契大考验** —— 选择题，看看你们有多了解对方
- **🎲 骰子挑战** —— 扔骰子，完成对应小任务（夸人、唱歌、发照片等）
- **📝 共同日记** —— 每天一个话题，各自写下心里话
- **🎨 接力故事** —— 一人写一句，编一个你们的故事
- **🌈 心情涂鸦** —— 在画布上涂鸦，截屏分享给TA
- **🎵 我们的歌单** —— 记录"让我想到你"的歌

> 因为是两个人各自的手机，互动数据各存各的。面对面时可以轮流用一部手机玩；异地时可以各自操作，然后截屏或口头分享结果。

### 📋 更多菜单（左上角按钮）

- **🌱 成长层** —— 记录情绪按钮（什么会戳爆你）、发火时真正需要什么、最近"被爱到"的瞬间
- **💬 启动句库** —— 吵架不知道说什么时，来这里抄一句发给TA
- **💑 见面管理** —— 见面倒计时、记录见面、心愿池

### ⚙️ 设置（右上角齿轮）

- 修改你和TA的名字
- 修改安全词（默认："TA好像饿了" = "我需要被照顾了"）
- 设置下次见面日期
- 调整字体大小
- **导出/导入数据** —— 最重要的同步功能！（见下方）

## 数据如何同步（重要！）

因为数据存在手机本地，两个人的数据是独立的。同步方法：

1. 你自己的数据有什么更新后，去 **设置 → 导出数据**
2. 会下载一个 `.json` 文件
3. 通过微信把文件发给TA
4. TA 在设置里点 **导入数据**，选择你发的文件
5. 数据会自动合并（不会覆盖TA自己的东西）

> 建议每周同步一次，或者在重要更新后同步。

## 吵架时怎么用（应急流程）

1. 感觉情绪要上头了 → **打开小花园**
2. 点 **急救** Tab
3. 选你的状态（我生气了 / TA生气了）
4. 看建议，冷静一下
5. 📋 复制一句合适的话 → 粘贴到微信发给TA
6. 如果实在说不出口 → 点"🚨 安全词提醒"，把安全词发过去
7. 冷静下来后 → 去 **补偿小卖部** 看看有没有需要处理的事
8. 彻底和好后 → 去 **成长层** 记录一件"被爱到的瞬间"

## 平时怎么用（日常维护）

1. 每天发完"我在"信号 → 打开 App 点一下打卡（+5分）
2. 感觉被暖到了 → 去成长层记录"被爱到的瞬间"（+5分）
3. 想TA了 → 去心愿池加一件下次见面想做的事
4. 无聊了 → 打开互动模块，抽个真心话或者掷个骰子
5. 攒够积分了 → 去奖励商店兑换，然后兑现承诺
6. 见面了 → 记录见面（+50分），勾选完成的心愿

## 犯了错怎么用

1. 去 **补偿小卖部** → 点击"+ 记录"
2. 如实填写：谁、什么事、红线还是黄线、怎么补偿
3. 完成补偿后 → 勾选"补偿完成 ✓"
4. 对方确认收到并原谅后 → 勾选"已收到原谅 ✓"
5. 事情正式翻篇，不要再翻旧账

## 小提示

- **安全词很重要**：约定一个只有你们懂的暗号（比如"TA好像饿了"），当任何一方说这个词时，另一方要暂停讲理，先回应情绪
- **不要把它当成考核工具**：积分是正向激励，不是绩效指标。忘了打卡没关系，想起来再点
- **补偿机制要当真**：记录了的补偿一定要完成+确认原谅，不要"算了算了"，那会积怨
- **互动模块是增进感情的**：无聊时或见面时一起玩，比刷手机有意思
- **数据定期备份**：导出 JSON 文件到电脑或云端，防止换手机数据丢失

---

## 隐私说明

- 所有数据存储在手机浏览器本地（localStorage）
- 不上传任何服务器，不经过任何第三方
- 只有导出和导入时数据才会离开手机
- 清除浏览器数据会导致数据丢失（所以记得定期导出备份！）
